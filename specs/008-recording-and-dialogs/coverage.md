# Feature 008 — acceptance coverage

Which evidence closes which requirement, in the same form as
`specs/005-form-values-and-downloads/coverage.md`. A requirement whose only evidence is a unit test
or a fixture is named as such rather than counted as proven on a browser. Gate runs are the attach
gate (`HALLPASS_CDP_ENDPOINT`, `tests/e2e/packaged/agent-*.spec.ts`); probe runs are `claude -p --model
sonnet` as the caller (`tests/acceptance/probe-004/`), reports under `…/reports/`.

**Acceptance standard (004, memory 2026-09-09)**: real sites on the owner's branded Chrome 152, a
coding agent as the caller, nothing left for the owner. **Everything below was measured on
Playwright Chromium 151 in attach mode** with a private `LOCALAPPDATA` (the recipe is in
`docs/operations-guide.md` §9). The owner's branded Chrome run was added on 2026-09-19 09:05 (Chrome 153 by then) — see the
Runs table; only the open observation remains open.
