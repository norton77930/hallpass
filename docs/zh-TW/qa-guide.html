Hallpass(瀏覽器代理橋接)· 試用指南 · 0.6.0

讓你的 AI 工具幫你操作 Chrome

裝一次、配對一次,之後在 CodeBuddy 或 Cursor 的聊天視窗裡用中文下指令就好。AI 每一個會改變網頁的動作,都要經過你在側欄的同意。2026-09-23 · 版本 0.6.0。

它會做什麼安裝(10 分鐘)第一次使用側欄怎麼看三種授權試試這些指令錄製 GIF對話框中斷與兩張新卡片注意回報問題移除

它會做什麼

你在 AI 工具的聊天視窗說「打開維基百科,找『Python』條目,把第一段唸給我」,AI 就會在你的 Chrome 裡開分頁、點連結、讀內容——用的是你的瀏覽器、你的登入狀態,沒有任何東西送到其他伺服器。

AI 在動的分頁會被圈成一個 Agent 群組,頁面上方有橫幅;右邊側欄看得到哪個 AI 在動哪個網站,隨時可以按「停止」。

安裝(10 分鐘,做一次)

你需要Windows 10/11 的 Chrome,Node 24(在終端機打 node -v;沒有的話到 nodejs.org 下載 LTS 版),以及安裝包 hallpass-0.6.0.zip。
已經裝過 0.3.0、0.4.0 或 0.5.0?把新的 zip 解壓縮到同一個資料夾蓋掉舊的,再執行一次 install.ps1(0.6.0 的上傳資料夾詢問需要新版的本機主機),最後到 chrome://extensions 對這個擴充功能按重新載入。沒有新的權限要同意;配對、每個網站的模式、config.json 裡的上傳資料夾都會留著。
已經裝過 0.2.0?0.3.0 改名為 Hallpass:解壓縮新 zip、執行 install.ps1(它會移除舊的 host 註冊並告訴你;舊資料夾 %LOCALAPPDATA%\poc-agent-host 可自行刪除)、重新載入擴充功能(名稱會變成 Hallpass,ID 不變,配對與網站設定都留著)、在 AI 工具的 MCP 設定把 poc-browser 換成 hallpass 並更新路徑;上傳白名單在新的 config.json 重填。工具前綴變成 mcp__hallpass__…。
已經裝過 0.1.0 或 0.1.1?升級就是:把新的 zip 解壓縮到同一個資料夾蓋掉舊的,再執行一次 install.ps1,最後到 chrome://extensions 對這個擴充功能按重新載入。0.2.0 多一個 offscreen 權限(錄影時在背景頁把畫面編成 GIF),所以 Chrome 會問一次要不要接受新權限,同意即可。配對和每個網站的模式都會留著,config.json 裡填過的上傳白名單也不會被蓋掉。安裝包 README.md 第 2.1 節是同一份說明。
  1. 解壓縮把 zip 解到一個固定的資料夾,例如 D:\hallpass(之後不要移動它——安裝會記住這個位置)。
  2. 跑安裝腳本在那個資料夾裡,對 install.ps1 按右鍵 →「使用 PowerShell 執行」。看到「安裝完成」就好;它會把兩段設定印在畫面上並複製到剪貼簿,下一步會用到。 
    # 如果右鍵沒有選項,開 PowerShell 在該資料夾執行:
powershell -ExecutionPolicy Bypass -File .\install.ps1
  3. 在 Chrome 載入擴充功能網址列打 chrome://extensions → 右上角開啟「開發人員模式」→「載入未封裝項目」→ 選解壓資料夾裡的 extension。看到「Hallpass 瀏覽器代理橋接」就對了;把它釘在工具列。
  4. 告訴你的 AI 工具這個 server 在哪用你自己的工具,二選一:

    CodeBuddy

    1. 側欄對話面板右上角 CodeBuddy Settings
    2. 切到 MCP 頁籤 → 添加 MCP
    3. 把下面這段貼進 JSON 編輯器(路徑換成 install.ps1 印出來的那一行,剪貼簿裡就有)
    4. 存檔,在 MCP 清單對 hallpass 按「嘗試運行」,綠燈就好

    "type": "stdio",
    "command": "node",
    "args": ["D:\\hallpass\\host\\mcp-server.js"],
    "description": "Hallpass" } } }

    Cursor

    1. Settings(Ctrl+Shift+J)→ 左邊 MCP
    2. Add new global MCP server(會開 ~\.cursor\mcp.json)
    3. 貼上下面這段,路徑同上
    4. 存檔;MCP 頁面上 hallpass 變綠、列出工具就好
    { "mcpServers": { "hallpass": {
    "command": "node",
    "args": ["D:\\hallpass\\host\\mcp-server.js"] } } }

    用其他工具(Claude Code、Claude Desktop、Codex CLI…)也可以,設定位置在安裝包的 README.md。

第一次使用

  1. Chrome 開著,側欄打開點工具列的圖示(或按 Alt+A)。第一次會看到「還沒有 agent 連上這個瀏覽器」——正常。
  2. 在 AI 工具裡下第一個指令例如:「用瀏覽器打開 https://en.wikipedia.org,告訴我首頁標題」。
  3. 按「允許配對」側欄會跳出配對卡,寫著是哪個工具想連上來。45 秒內按「允許配對」;逾時那一次指令會失敗,再下一次就會再問。配對只做一次,以後 Chrome 重開也記得。
  4. 第一個會改變網頁的動作,會問你點擊、輸入、跳頁……第一次做時側欄跳同意卡:「XX 想在 某網站 上點擊頁面元素」。三個按鈕:只允許這一次(過了這一步,下一步再問)/ 這個網站以後都允許(這個網站不再問)/ 拒絕。

側欄怎麼看

已連線、沒在動

綠點 +「已連線 · 工具名稱」,下面是「允許 agent 操作的網站」清單。「更多選項」裡有解除配對。

正在動

每一個 AI session 一張卡:它在哪個網站、狀態(執行中 / 等你決定)。中斷 = 只停掉正在做的那一步,AI 和分頁都留著(見中斷與兩張新卡片);停止 = 這個 AI 結束、分頁留給你;還我分頁 = 分頁拿回來,AI 還在,它可以再開自己的。

三種授權,選一個就好

模式白話建議
每次都先問我AI 每做一個會改變網頁的動作,都先問你預設。不熟的網站、有帳號的網站
照計畫AI 一次提出好幾步(例如填完整張表單),你看過一次核准,它就照著做;超出計畫的還是會問固定流程的測試
不再詢問這個網站完全不問只給你信任、沒有個資的測試站

另外兩個開關:診斷(讓 AI 看該網站的 console / 網路請求、在頁面跑程式;測試網頁時才需要)、上傳(AI 只能上傳你在 %LOCALAPPDATA%\hallpass\config.json 的 uploadRoots 列出的資料夾裡的檔案;預設是空的)。0.6.0 起,清單外的檔案不會直接失敗,而是當場問你,你也可以從卡片上把資料夾加進清單。

試試這些指令

直接在 CodeBuddy / Cursor 的聊天視窗用中文說,AI 會自己挑工具:

  • 「用瀏覽器打開 https://github.com/octocat/Hello-World,把 README 前三段唸給我。」
  • 「在這個分頁找『Sign in』連結點下去,告訴我現在的網址。」
  • 「打開 https://httpbin.org/forms/post,customer name 填 Ada,size 選 Large,不要送出;讀回欄位的值給我看。」
  • 「開兩個分頁,分別打開 A 站和 B 站,比較兩邊的標題。」
  • 「到 https://github.com/octocat/Hello-World/archive/refs/heads/master.zip 把檔案下載下來,告訴我存在哪裡。」(檔案會落在 Chrome 的下載資料夾)
  • 「截一張現在頁面的圖。」
  • 「截一張現在頁面的圖，再把那張圖附到頁面上的『選擇檔案』欄位。」（0.5.0 新增：截圖不會存成檔案，只在本機保留 5 分鐘；放進頁面算一次「改頁面」，所以會照網站模式問你）

要 AI 操作你已經開著的分頁:說「接手我現在這個分頁」——它會用 tabs_claim 拿走沒有其他 AI 持有的分頁。

錄製 GIF

叫 AI 把它接下來做的每一步錄下來,最後給你一張會動的 GIF,可以直接貼進測試單。它錄的不是螢幕錄影,而是它自己的動作:每做一個會改變頁面的動作就拍一張,再在圖上畫出它點在哪、做了什麼。

怎麼叫它錄

在 CodeBuddy / Cursor 的聊天視窗直接說就好,例如:

先開始錄製,然後打開 https://……/login,用測試帳號登入,
點「我的訂單」,確認第一筆訂單編號是 A123,最後匯出成 TC-1234。
  • 「開始錄製」之後,每一個會改變頁面的動作(點擊、輸入、按鍵、捲動、跳頁、截圖、上傳檔案、調整視窗、回答對話框)各拍一張;說「開始錄製」的當下也會先拍一張目前的畫面。讀取類的動作(讀頁面、找元素)不拍。
  • AI 一次送出好幾步(browser_batch)時,裡面每一步各算一張,不是整批一張。
  • 「匯出成 TC-1234」會產生 TC-1234.gif。不指定名字就用時間命名,像 agent-recording-20260919-143000.gif。名字只能用英數字、空白、-、_、.(不能用 . 開頭),最多 80 個字;不合的名字會當場被擋下來,不會寫出任何檔案。

檔案會落在哪

落在 Chrome 的下載資料夾,不會跳「另存新檔」。同名檔案已經在的話,瀏覽器會自己改成 TC-1234 (1).gif——AI 回報的是真正存下來的那個名字,以它說的為準。用瀏覽器或任何看圖程式打開就會自己循環播放(每張約 0.8 秒,最後一張停久一點)。

上限與收尾

  • 一次錄製最多 200 張。滿了之後動作照做,但不再拍;AI 每一個回覆都會看到「錄滿了」(recording.full),這時該叫它匯出,或清掉重錄。
  • 那個 AI 的工作階段結束時(你按停止、它自己結束、或連線斷掉),只要還有沒匯出的畫面,會自動用時間名存一份,不會白錄一場。
  • 側欄那張 session 卡片上會有一行:錄製中就是「錄製中 · 12 幀」,滿了是「錄製已滿 200 幀,等待匯出」,匯出完變成「已匯出 TC-1234.gif」。

對話框

網頁自己跳出來的那種小視窗:alert(只有一個確定)、confirm(確定 / 取消)、prompt(要你填一格),還有離開頁面前的「離開此網站?」。以前 AI 碰到它們會整個卡住,現在它聽得到,也答得了——而且按不按「確定」由你決定。

對話框開著的時候,AI 對那個分頁做的其他動作會立刻被擋回去(實測約 0.006 秒),不會再讓你等半天;它應該轉頭來處理這個對話框。

每次都先問我 模式

  • AI 要按「確定」時,側欄會跳同意卡:「XX 想按下網頁確認框的『確定』」,底下原封不動引用網頁那句話,你看得到自己正在同意什麼。
  • 按 拒絕 = 幫你按網頁的取消,頁面不會就這樣掛在那裡。
  • 如果這個對話框是你剛剛才允許的那個動作馬上引出來的(1 秒內、同一個分頁),不會再問你第二次:側欄改出一張不用回答的通知——「網頁跳出確認框 · 已按 確定 · 承接你剛允許的…」。一次允許只承接一個對話框,晚三秒才跳出來的那種還是會問你。
  • 按取消(關掉對話框)和 alert 的確定永遠不會問你:它們不會讓網頁多做任何事。

照計畫 和 不再詢問 模式

不會跳卡,AI 自己回答。但每一個對話框都會寫進那張 session 卡片的近期活動:「某網站 說:那句話」,後面接結果(已按 確定 / 已按 取消 / 你已拒絕 / 你自己關掉了)。想知道剛剛網頁問了什麼,看那裡,最多留最近 20 筆。

「離開此網站?」

頁面上有還沒存的東西時,跳頁或關分頁會跳這個。預設一律留在原頁,AI 會收到「被離開提示擋住」並回報給你,沒存的東西不會因為 AI 的一步就不見。真的要離開,AI 必須明講再要求一次;那在「每次都先問我」模式下會跳一張卡:「放棄 某網站 上未儲存的變更並離開」,由你決定。

你自己跳出來的「離開此網站?」,擴充功能不碰你按連結、關分頁時網頁問的那一句,還是你自己回答,AI 不會替你按。

中斷,和兩張新的卡片(0.6.0)

中斷:只停這一步,不關掉 AI

session 卡片上,停止旁邊多了一個中斷。它只結束 AI 正在做的那一步——等頁面、等你回答的卡片、跑很久的批次步驟都算——一秒內就會有結果,其他東西全部留著:配對、分頁和分頁群組、網站模式、正在錄的 GIF。AI 會被告訴「這一步是你中斷的」,還會知道剛剛有沒有東西已經送進頁面(例如字已經打進去了),它自己決定要不要重做。沒有東西在跑的時候按下去,卡片上只會出現一行「目前沒有正在執行的步驟」,什麼都不會發生。
要整個結束還是按停止,行為跟以前一樣。

卡片一:分頁跑到別的網站

AI 點了一個連結,頁面把它轉到別的網站(登入服務、短網址、廣告跳轉)——而那個網站你從來沒決定過。這時側欄會跳一張卡片,兩個網站都寫出來:「分頁從 https://a.example 到了 https://b.example」。三個按鈕:

  • 繼續:這次工作階段都可以,關掉 Chrome 就忘了。
  • 一律允許:記住「A → B」這一組,以後這個跳轉不再問。
  • 拒絕:只擋這一次呼叫,AI 收到「擁有者拒絕了這次跳站」;session 不會結束,下一次它再動那個分頁還是會問你。

要注意的是:問的不是造成跳轉的那一次呼叫,而是下一次對那個分頁的呼叫(連「讀一下這頁」都算)。AI 想離開那個網站(換去別的網址、關掉分頁、把分頁還你)不會被擋,它隨時走得掉。本機位址(127.0.0.1 / localhost)之間的跳轉不會問。

卡片二:要上傳的檔案不在你允許的資料夾裡

以前 AI 要上傳 uploadRoots 以外的檔案會直接失敗,你得自己去改 config.json。現在會當場問你:卡片上完整列出每一個檔案的路徑,以及每個檔案所在的資料夾(按「以後都可以」記住的就是這個資料夾)。三個按鈕:這些檔案這次就好、這些資料夾以後都可以、拒絕。卡片最多等你 125 秒;沒回答就當作沒上傳,AI 會被告訴沒有人回答。

幾個會遇到的情況:磁碟機根目錄(C:\)或網路分享根目錄不會被加進清單,那些檔案只會「這次就好」放行,AI 的答案裡會說原因;檔案太多或總量太大,還是會直接被拒,不會先問你(免得你為了一個怎樣都會失敗的呼叫去放寬清單)。

「記住的決定」在側欄哪裡看、怎麼收回

在「允許 agent 操作的網站」清單下面,現在多了兩種列表,每一列右邊都有撤銷:

  • 允許的跳站組合:一列寫「A → B」,後面寫上次用到是什麼時候(從來沒用過就寫沒用過)。撤銷之後,下次再跳就會重新問你。
  • 允許上傳的資料夾:一列一個資料夾路徑。撤銷之後,那個資料夾裡的檔案再被上傳就會重新問你。

這兩份清單只有你改得動。AI 那一端拿得到的工具,沒有任何一個讀得到清單、也加不進去——它只能透過上面那張卡片、由你按下去。

升級提醒這兩張卡片需要新版的本機主機。請重新執行安裝包裡的 install.ps1;舊版主機遇到允許資料夾以外的檔案,只會像 0.5.0 一樣直接拒絕(答案是 upload-not-allowed),不會問你。

注意

Chrome 若跳出「已開始對此瀏覽器進行偵錯」的提示,不要按「取消」那是 AI 輸入文字、點擊的必要通道。按了取消,之後所有點擊都會失敗;要按側欄的「停止」再重來。
AI 看得到你登入後的畫面它用的是你這個 Chrome 的登入狀態。銀行、健康、公司內部系統這類網站,不要設「不再詢問」;測試用另一個 Chrome profile 更安心。密碼與信用卡欄位的值會被遮掉,AI 讀不到。
  • chrome:// 頁面、Chrome 線上應用程式商店:AI 拿不到,會回「受限頁面」。
  • 截圖時畫面會切一下分頁再切回來,正常。
  • 多個 AI 工具同時用同一個 Chrome 可以,各自有自己的分頁群組。
  • Chrome 關掉,連線就斷;重開 Chrome 十秒內自動接回,AI 工具不用重啟。
  • 側欄語言跟著 Chrome 的介面語言:繁中顯示中文,其他顯示英文。

AI 說 not-paired / 逾時配對卡沒在 45 秒內按;再下一次指令、按「允許配對」
AI 說 input-unavailable偵錯提示被取消了;側欄按「停止」再重來
AI 說 not-yours那個分頁不是它的(是你的或別的 AI 的);叫它「接手這個分頁」或自己開新分頁

回報時請附:側欄「技術資訊」展開後的內容、%LOCALAPPDATA%\hallpass\relay.log、你下的指令與 AI 的回覆。日誌只有代碼,沒有網頁內容,可以放心附。

移除

  1. 解壓資料夾裡對 uninstall.ps1 右鍵 →「使用 PowerShell 執行」。
  2. chrome://extensions 移除「Hallpass」。
  3. 從 AI 工具的 MCP 設定刪掉 hallpass。
